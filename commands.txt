Hi Team,
Please follow the below steps to configure VNC in SAS server.
Environment
Red Hat Enterprise Linux 8
Prerequisites
 	The gdm, vnc, vnc-server, and xinetd packages must be installed:
# yum install gdm tigervnc tigervnc-server xinetd
 	The xinetd service must be enabled:
# systemctl enable xinetd.service
 	The default runlevel must be runlevel 5 (graphical.target):
To get the currently set default,
# systemctl get-default
If needed, you can change the default runlevel by
# systemctl set-default graphical.target
Setup
 	Set up GDM to enable XDMCP. 
edit the /etc/gdm/custom.conf file enable xdmcp:
[xdmcp]
Enable=true
 	Create the /etc/xinetd.d/xvncserver file with following content:
 
service vnc01-1024x768x24
{
        disable = no
        protocol = tcp
        socket_type = stream
        wait = no
        user = nobody
        server = /usr/bin/Xvnc
        server_args = -inetd -query localhost -once -geometry 1024x768 -depth 24 securitytypes=none
}
In the server_args section, the -query localhost option makes each Xvnc instance query localhost for an xdmcp session.
The -depth <depth> option specifies the pixel depth (in bits) of the VNC desktop to be created. Possible values are 8, 15, 16 and 24. Anything else is likely to cause strange behavior in applications.
WARNING: On RHEL 7 or 8 with GNOME, always set the pixel depth to 24-bit. Otherwise, you might experience graphical artifacts and other odd rendering behavior.
 
 	Edit the /etc/services file to define the services.
# VNC xinetd GDM base
Vnc01-1024x768x24 5901/tcp
 	To ensure that the configuration changes take effect, reboot the system.
 
Now clients will be able to access the GDM login window and login to any system account.
 
 
Known Issue:
 
 
You can create a file /etc/polkit-1/rules.d/100-stop-package-sources-refresh.rules with the following content :
 
polkit.addRule(function(action, subject) {
if (action.id == "org.freedesktop.packagekit.system-sources-refresh")
{
   return polkit.Result.NO;
}
} )
