To enable log rotation and keep only two days' worth of log files in Red Hat Enterprise Linux (RHEL) 8, you can use the logrotate utility and configure the rotation parameters. Follow these steps:
 
Open or create a configuration file for the log rotation. Typically, logrotate configurations are located in /etc/logrotate.conf or in separate files under the /etc/logrotate.d/ directory.
 
bash
Copy code
sudo nano /etc/logrotate.d/mylog
Replace mylog with an appropriate name for your log file.
 
Inside the configuration file, specify the log file or files you want to rotate and configure the rotation parameters. For example:
 
plaintext
Copy code
/path/to/your/logfile {
    rotate 2
    daily
    compress
    missingok
    notifempty
}
rotate 2: Keep only 2 rotated log files.
daily: Rotate logs daily.
compress: Compress rotated log files.
missingok: Do not generate an error if the log file is missing.
notifempty: Do not rotate the log file if it is empty.
Adjust the /path/to/your/logfile to the actual path of your log file.
 
Save the file and exit the text editor.
 
You can manually run log rotation to test your configuration:
 
bash
Copy code
sudo logrotate -vf /etc/logrotate.d/mylog
The -v option is for verbose mode, and the -f option forces log rotation.
 
Check if the log rotation is working correctly. Verify that only two days' worth of log files are retained:
 
bash
Copy code
ls -lh /path/to/your/logfile*
The above command should show only two rotated log files.

bash
Copy code

bash
Copy code
